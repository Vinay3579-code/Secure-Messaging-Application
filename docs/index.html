SecureMsg — End-to-End Encrypted Messaging System

Cryptography & Network Security (CNS) Course Project by Team 04. Implements RSA-2048-PSS signed Diffie-Hellman (RFC 3526), transcript-salted HKDF-SHA256, a per-message symmetric hash ratchet, AES-256-CBC + HMAC-SHA256 (Encrypt-then-MAC), encrypted file sharing up to 10 MB, and a 5-scenario Attack Lab verified by 47 automated tests.

SEMANTIC COLOR LEGEND
  • Violet — Asymmetric Key Agreement & Identity (DH-2048, RSA-PSS)
  • Cyan — Symmetric Cipher & Encrypted Blobs (AES-256-CBC, TLS)
  • Emerald — Verified Integrity & Forward Secrecy (HMAC, Ratchet)
  • Amber — Forensic Evidence & Wire Inspection (SQLite, Inspector)
  • Rose — Blocked Attacks (MITM, Tamper, Replay 409, Padding Oracle)
